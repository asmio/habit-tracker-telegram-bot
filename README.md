# Habit Tracker Telegram Bot

Telegram-бот для отслеживания привычек: трекеры с пунктами, ежедневные отметки и часовой пояс пользователя, от которого зависит, когда начинается новый день.

## Стек

- Node.js 22+ и TypeScript (strict)
- [grammY](https://grammy.dev) — фреймворк для бота
- Drizzle ORM + SQLite (better-sqlite3)
- zod — валидация переменных окружения

## Быстрый старт

```bash
npm install
cp .env.example .env   # впишите BOT_TOKEN от @BotFather
npm run db:migrate
npm run dev
```

## Переменные окружения

| Переменная  | Описание                | По умолчанию         |
| ----------- | ----------------------- | -------------------- |
| `BOT_TOKEN` | токен бота (обязателен) | —                    |
| `DB_PATH`   | путь к файлу SQLite     | `./habit-tracker.db` |

## Команды бота

| Команда     | Что делает                                                       |
| ----------- | ---------------------------------------------------------------- |
| `/start`    | приветствие; при первом обращении просит выбрать часовой пояс    |
| `/timezone` | смена часового пояса: список, ввод названия или геолокация       |
| `/new`      | создать трекер                                                   |
| `/additem`  | добавить пункты в трекер (по одному на строку)                   |
| `/today`    | пункты трекеров на сегодня; нажатие на кнопку ставит/снимает отметку |

## Скрипты

| Скрипт                | Назначение                                        |
| --------------------- | ------------------------------------------------- |
| `npm run dev`         | запуск с автоперезапуском (nodemon + ts-node)     |
| `npm run build`       | компиляция в `dist/`                              |
| `npm start`           | запуск скомпилированного бота                     |
| `npm run typecheck`   | проверка типов                                    |
| `npm run db:generate` | сгенерировать миграцию после изменения схемы      |
| `npm run db:migrate`  | применить миграции                                |
| `npm run db:studio`   | Drizzle Studio                                    |

## Структура

```
src/
  index.ts      точка входа
  config.ts     чтение и валидация переменных окружения
  logger.ts     логгер (интерфейс в types/logger.ts)
  bot/          создание бота, обработчик ошибок
  handlers/     команды и callback'и, по одному файлу на handler
  services/     бизнес-логика
  db/           схема Drizzle и подключение к SQLite
drizzle/        SQL-миграции
```

Слои: `handlers/ → services/ → db/`.
